# base64_codec_service

HTTP microservice die tekst codeert naar base64 en base64 decodeert naar tekst, met expliciete validatie en duidelijke, machine-leesbare foutmeldingen bij ongeldige invoer (ongeldige base64, verkeerde padding, niet-UTF8 resultaat, te grote payload).

## Lokaal draaien

```bash
docker build -t base64_codec_service .
docker run --rm -p 8005:8005 base64_codec_service
```

De service draait dan op http://localhost:8005


## Endpoints en testcommando's

### POST /encode

Codeert platte tekst naar base64. Optioneel url_safe voor URL-veilig alfabet (-_ i.p.v. +/) en optionele tekstencoding (default utf-8). Geeft 422 bij ontbrekende/lege of te grote invoer.

```bash
curl -X POST http://localhost:8005/encode -H 'Content-Type: application/json' -d '{"text": "Hallo wereld", "url_safe": false, "encoding": "utf-8"}'
```

**Response:**
```json
{
  "encoded": "SGFsbG8gd2VyZWxk",
  "input_bytes": 12,
  "output_length": 16,
  "url_safe": false,
  "encoding": "utf-8"
}
```

### POST /decode

Decodeert een base64-string naar tekst. Accepteert standaard en URL-safe alfabet; whitespace/newlines worden genegeerd. Bij ongeldige tekens, verkeerde padding of niet-decodeerbare bytes volgt een 400 met duidelijke error-code, uitleg en positie van het eerste ongeldige teken.

```bash
curl -X POST http://localhost:8005/decode -H 'Content-Type: application/json' -d '{"data": "SGFsbG8gd2VyZWxk", "encoding": "utf-8", "strict": true}'
```

**Response:**
```json
{
  "decoded": "Hallo wereld",
  "input_length": 16,
  "output_bytes": 12,
  "encoding": "utf-8",
  "detected_alphabet": "standard"
}
```

### POST /validate

Controleert of een string geldige base64 is zonder te decoderen naar tekst. Geeft altijd 200 met een valid-vlag en, indien ongeldig, de reden en positie.

```bash
curl -X POST http://localhost:8005/validate -H 'Content-Type: application/json' -d '{"data": "SGFsbG8gd2VyZWxk!!"}'
```

**Response:**
```json
{
  "valid": false,
  "error_code": "INVALID_BASE64_CHARACTER",
  "message": "Ongeldig base64-teken '!' op positie 16.",
  "position": 16
}
```

### GET /status

Health- en metadata-endpoint met servicenaam, versie, ondersteunde alfabetten en maximale payloadgrootte.

```bash
curl -X GET http://localhost:8005/status
```

**Response:**
```json
{
  "status": "ok",
  "service": "base64_codec_service",
  "version": "1.0.0",
  "supported_alphabets": [
    "standard",
    "url_safe"
  ],
  "max_input_bytes": 1048576
}
```
