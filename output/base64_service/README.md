# base64_service

HTTP microservice die tekst naar base64 encodeert en base64 terug naar tekst decodeert, met expliciete, duidelijke foutmeldingen bij ongeldige invoer (niet-base64 payload, verkeerde padding, niet-UTF8 resultaat, lege invoer). Ondersteunt standaard en URL-safe base64 alfabetten.

## Lokaal draaien

```bash
docker build -t base64_service .
docker run --rm -p 8004:8004 base64_service
```

De service draait dan op http://localhost:8004


## Endpoints en testcommando's

### POST /encode

Encodeert de meegegeven tekst naar base64. Optioneel URL-safe alfabet en het weglaten van padding. Geeft 422 met duidelijke foutmelding bij lege/ongeldige invoer.

```bash
curl -X POST http://localhost:8004/encode -H 'Content-Type: application/json' -d '{"text": "Hallo wereld", "url_safe": false, "strip_padding": false}'
```

**Response:**
```json
{
  "input_text": "Hallo wereld",
  "encoded": "SGFsbG8gd2VyZWxk",
  "alphabet": "standard",
  "input_bytes": 12,
  "output_length": 16
}
```

### POST /decode

Decodeert een base64 string terug naar tekst (UTF-8). Detecteert automatisch standaard en URL-safe alfabet en herstelt ontbrekende padding wanneer toegestaan. Geeft 422 met een duidelijke, specifieke foutmelding bij ongeldige base64 of niet-decodeerbare bytes.

```bash
curl -X POST http://localhost:8004/decode -H 'Content-Type: application/json' -d '{"data": "SGFsbG8gd2VyZWxk", "url_safe": false, "fix_padding": true}'
```

**Response:**
```json
{
  "input_data": "SGFsbG8gd2VyZWxk",
  "decoded": "Hallo wereld",
  "alphabet": "standard",
  "padding_fixed": false,
  "output_length": 12
}
```

### POST /validate

Controleert of een string geldige base64 is zonder te decoderen naar tekst; geeft altijd 200 met een boolean en indien ongeldig een uitleg met de reden en positie van het eerste ongeldige teken.

```bash
curl -X POST http://localhost:8004/validate -H 'Content-Type: application/json' -d '{"data": "SGFsbG8g@d2VyZWxk"}'
```

**Response:**
```json
{
  "data": "SGFsbG8g@d2VyZWxk",
  "valid": false,
  "reason": "Ongeldig teken '@' op positie 8 voor base64 alfabet",
  "error_code": "INVALID_BASE64_CHARACTER"
}
```

### GET /status

Health/status endpoint met servicenaam, versie en ondersteunde alfabetten.

```bash
curl -X GET http://localhost:8004/status
```

**Response:**
```json

  "supported_alphabets": [
```
