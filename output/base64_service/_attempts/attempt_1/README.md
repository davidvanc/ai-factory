# base64_service

HTTP microservice die tekst encodeert naar base64 en base64 decodeert naar tekst, met expliciete, duidelijke foutmeldingen bij ongeldige invoer (verkeerde padding, niet-base64 tekens, ongeldige UTF-8 payload, te grote input).

## Lokaal draaien

```bash
docker build -t base64_service .
docker run --rm -p 8004:8004 base64_service
```

De service draait dan op http://localhost:8004


## Endpoints en testcommando's

### POST /encode

Encodeert de meegegeven tekst naar base64. Optioneel kan met 'url_safe' de URL-veilige base64-variant (-, _) gekozen worden en met 'strip_padding' het weglaten van '=' padding. Tekst wordt als UTF-8 gecodeerd voordat base64 wordt toegepast.

```bash
curl -X POST http://localhost:8004/encode -H 'Content-Type: application/json' -d '{"text": "Hallo wereld", "url_safe": false, "strip_padding": false}'
```

**Response:**
```json
{
  "encoded": "SGFsbG8gd2VyZWxk",
  "input_length": 12,
  "output_length": 16,
  "url_safe": false,
  "padding_stripped": false
}
```

### POST /decode

Decodeert een base64-string terug naar tekst. Ondersteunt standaard en URL-veilige base64 en ontbrekende padding (wordt automatisch aangevuld). Geeft 422 met duidelijke foutmelding bij ongeldige base64-tekens, onmogelijke lengte of niet-UTF-8 resultaat.

```bash
curl -X POST http://localhost:8004/decode -H 'Content-Type: application/json' -d '{"data": "SGFsbG8gd2VyZWxk", "url_safe": false}'
```

**Response:**
```json
{
  "decoded": "Hallo wereld",
  "input_length": 16,
  "output_length": 12,
  "url_safe": false,
  "padding_added": 0
}
```

### GET /status

Healthcheck en servicemetadata (naam, versie, ondersteunde alfabetten en maximale inputgrootte).

```bash
curl -X GET http://localhost:8004/status
```

**Response:**
```json
{
  "status": "ok",
  "service": "base64_service",
  "version": "1.0.0",
  "alphabets": [
    "standard",
    "url_safe"
  ],
  "max_input_bytes": 1048576
}
```
