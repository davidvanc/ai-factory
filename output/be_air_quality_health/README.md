# be_air_quality_health

Python tool die actuele Belgische luchtkwaliteitsdata (PM2.5 en PM10) ophaalt van openbare bronnen (IRCEL-CELINE, opendata.brussels.be, AQICN) en een gezondheidsrisico-score berekent op basis van WHO-richtlijnen (PM2.5 jaargemiddelde 5 µg/m³, 24u 15 µg/m³; PM10 jaargemiddelde 15 µg/m³, 24u 45 µg/m³).

## Lokaal draaien

```bash
docker build -t be_air_quality_health .
docker run --rm be_air_quality_health
```

Voor een CLI tool met argumenten:
```bash
docker run --rm be_air_quality_health python -m src.main --help
```

## Tests draaien

```bash
docker run --rm be_air_quality_health python -m pytest tests/ -v
```
