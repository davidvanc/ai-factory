# be_air_quality_monitor

Python tool die actuele Belgische luchtkwaliteitsdata (PM2.5 en PM10) ophaalt van openbare bronnen zoals de World Air Quality Index API (aqicn.org) en OpenAQ, en een gezondheidsrisico-score berekent op basis van de WHO richtlijnen (PM2.5: 15 µg/m³ 24u, 5 µg/m³ jaar; PM10: 45 µg/m³ 24u, 15 µg/m³ jaar).

## Lokaal draaien

```bash
docker build -t be_air_quality_monitor .
docker run --rm be_air_quality_monitor
```

Voor een CLI tool met argumenten:
```bash
docker run --rm be_air_quality_monitor python -m src.main --help
```

## Tests draaien

```bash
docker run --rm be_air_quality_monitor python -m pytest tests/ -v
```
