# blog_service

Een HTTP microservice voor een eenvoudige blog met posts en comments. Ondersteunt het aanmaken en ophalen van posts en het toevoegen en ophalen van comments per post.

## Lokaal draaien

```bash
docker build -t blog_service .
docker run --rm -p 8026:8026 blog_service
```

De service draait dan op http://localhost:8026


## Endpoints en testcommando's

### POST /posts

Maak een nieuwe post aan met title en body. Retourneert de gemaakte post met id en created_at.

```bash
curl -X POST http://localhost:8026/posts -H 'Content-Type: application/json' -d '{"title": "Hello World", "body": "This is my first post"}'
```

**Response:**
```json
{
  "id": 1,
  "title": "Hello World",
  "body": "This is my first post",
  "created_at": "2024-01-15T10:30:00"
}
```

### GET /posts

Lijst alle posts op.

```bash
curl -X GET http://localhost:8026/posts
```

**Response:**
```json
[
  {
    "id": 1,
    "title": "Hello World",
    "body": "This is my first post",
    "created_at": "2024-01-15T10:30:00"
  }
]
```

### GET /posts/{id}

Haal een specifieke post op via id. Retourneert 404 als de post niet bestaat.

```bash
curl -X GET http://localhost:8026/posts/1
```

**Response:**
```json
{
  "id": 1,
  "title": "Hello World",
  "body": "This is my first post",
  "created_at": "2024-01-15T10:30:00"
}
```

### POST /posts/{id}/comments

Voeg een comment toe aan een specifieke post. Retourneert 404 als de post niet bestaat.

```bash
curl -X POST http://localhost:8026/posts/1/comments -H 'Content-Type: application/json' -d '{"text": "Great post!"}'
```

**Response:**
```json
{
  "id": 1,
  "post_id": 1,
  "text": "Great post!",
  "created_at": "2024-01-15T10:35:00"
}
```

### GET /posts/{id}/comments

Lijst alle comments op voor een specifieke post. Retourneert 404 als de post niet bestaat.

```bash
curl -X GET http://localhost:8026/posts/1/comments
```

**Response:**
```json
[
  {
    "id": 1,
    "post_id": 1,
    "text": "Great post!",
    "created_at": "2024-01-15T10:35:00"
  }
]
```
