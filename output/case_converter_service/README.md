# case_converter_service

Een HTTP microservice die tekst converteert tussen verschillende case-formaten: UPPERCASE, lowercase, Title Case, snake_case, kebab-case en camelCase.

## Lokaal draaien

```bash
docker build -t case_converter_service .
docker run --rm -p 8011:8011 case_converter_service
```

De service draait dan op http://localhost:8011


## Endpoints en testcommando's

### POST /convert

Converteert een gegeven tekst naar het opgegeven case-formaat.

```bash
curl -X POST http://localhost:8011/convert -H 'Content-Type: application/json' -d '{"text": "hello world example", "target_case": "camel"}'
```

**Response:**
```json
{
  "original": "hello world example",
  "target_case": "camel",
  "result": "helloWorldExample"
}
```

### POST /convert/all

Converteert een gegeven tekst naar alle ondersteunde case-formaten tegelijk.

```bash
curl -X POST http://localhost:8011/convert/all -H 'Content-Type: application/json' -d '{"text": "hello world example"}'
```

**Response:**
```json
{
  "original": "hello world example",
  "upper": "HELLO WORLD EXAMPLE",
  "lower": "hello world example",
  "title": "Hello World Example",
  "snake": "hello_world_example",
  "kebab": "hello-world-example",
  "camel": "helloWorldExample"
}
```

### GET /cases

Geeft een lijst van alle ondersteunde case-formaten terug.

```bash
curl -X GET http://localhost:8011/cases
```

**Response:**
```json
{
  "supported_cases": [
    "upper",
    "lower",
    "title",
    "snake",
    "kebab",
    "camel"
  ]
}
```

### GET /status

Geeft de status van de service terug.

```bash
curl -X GET http://localhost:8011/status
```

**Response:**
```json
{
  "status": "ok",
  "service": "case_converter_service"
}
```
