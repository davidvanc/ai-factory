# date_format_converter

Een microservice die datum strings omzet tussen verschillende formaten: ISO 8601, Europees (DD-MM-YYYY), Amerikaans (MM/DD/YYYY) en Unix timestamp.

## Lokaal draaien

```bash
docker build -t date_format_converter .
docker run --rm -p 8007:8007 date_format_converter
```

De service draait dan op http://localhost:8007


## Endpoints en testcommando's

### POST /convert

Converteert een datum string van een bron-formaat naar een doel-formaat. Ondersteunde formaten: 'iso', 'eu', 'us', 'unix'.

### POST /detect

Detecteert automatisch het formaat van een datum string.

### GET /formats

Geeft een lijst van alle ondersteunde datumformaten met voorbeelden.

### GET /status

Health check endpoint.

### GET /health

```bash
curl http://localhost:8007/health
```
