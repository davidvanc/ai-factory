# day_of_week_service

Microservice die de dag van de week berekent voor een gegeven datum (YYYY-MM-DD) met behulp van Zeller's congruence.

## Lokaal draaien

```bash
docker build -t day_of_week_service .
docker run --rm -p 8023:8023 day_of_week_service
```

De service draait dan op http://localhost:8023


## Endpoints en testcommando's

### POST /day-of-week

Berekent de dag van de week voor een datum in YYYY-MM-DD formaat via Zeller's congruence.

```bash
curl -X POST http://localhost:8023/day-of-week -H 'Content-Type: application/json' -d '{"date": "2025-01-15"}'
```

**Response:**
```json
{
  "day": "Wednesday"
}
```
