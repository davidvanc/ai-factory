# email_validator_service

Microservice die e-mailadressen valideert volgens RFC 5322 met strikte regels (geen opeenvolgende punten, verplichte TLD, alleen geldige karakters).

## Lokaal draaien

```bash
docker build -t email_validator_service .
docker run --rm -p 8025:8025 email_validator_service
```

De service draait dan op http://localhost:8025


## Endpoints en testcommando's

### POST /validate

Valideert een e-mailadres volgens RFC 5322 regels. Retourneert of het adres geldig is en een reden indien ongeldig.

```bash
curl -X POST http://localhost:8025/validate -H 'Content-Type: application/json' -d '{"email": "john.doe@example.com"}'
```

**Response:**
```json
{
  "valid": true,
  "reason": "valid email address"
}
```
