# french_number_converter

HTTP microservice die getallen (0 tot 1.000.000.000.000.000) omzet naar correct geschreven Franse tekst, inclusief regels voor quatre-vingts, soixante-dix, quatre-vingt-dix, mille, million en milliard.

## Lokaal draaien

```bash
docker build -t french_number_converter .
docker run --rm -p 8009:8009 french_number_converter
```

De service draait dan op http://localhost:8009


## Endpoints en testcommando's

### POST /convert

Zet een geheel getal om naar correct geschreven Franse tekst.

```bash
curl -X POST http://localhost:8009/convert -H 'Content-Type: application/json' -d '{"number": 80}'
```

### GET /convert

Zet een geheel getal om naar Franse tekst via query parameter.

```bash
curl -X GET 'http://localhost:8009/convert?number=91'
```

### GET /status

Health check endpoint voor de service.

```bash
curl -X GET http://localhost:8009/status
```

### GET /health

```bash
curl http://localhost:8009/health
```
