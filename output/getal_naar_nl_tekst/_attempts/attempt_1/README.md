# getal_naar_nl_tekst

HTTP microservice die numerieke waarden omzet naar correct gespelde Nederlandse tekst, inclusief trema's, decimalen en negatieve getallen.

## Lokaal draaien

```bash
docker build -t getal_naar_nl_tekst .
docker run --rm -p 8008:8008 getal_naar_nl_tekst
```

De service draait dan op http://localhost:8008


## Endpoints en testcommando's

### POST /convert

Zet een getal (geheel, decimaal of negatief) om naar Nederlandse tekst.

### GET /convert

Zet een getal via query parameter om naar Nederlandse tekst.

### GET /status

Health-check endpoint.

### GET /health

```bash
curl http://localhost:8008/health
```


## Tests draaien

```bash
docker run --rm getal_naar_nl_tekst python -m pytest tests/ -v
```
