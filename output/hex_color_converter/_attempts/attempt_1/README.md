# hex_color_converter

Een Python CLI tool die een hex kleurcode (zoals #FF5733) omzet naar RGB en HSL waarden.

## Lokaal draaien

```bash
docker build -t hex_color_converter .
docker run --rm hex_color_converter
```

Voor een CLI tool met argumenten:
```bash
docker run --rm hex_color_converter python -m src.main --help
```

## Tests draaien

```bash
docker run --rm hex_color_converter python -m pytest tests/ -v
```
