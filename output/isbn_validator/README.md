# isbn_validator

Een microservice die ISBN-10 en ISBN-13 codes valideert met correcte checksum-verificatie. Accepteert input met of zonder streepjes en retourneert of de code geldig is plus het formaat type.

## Lokaal draaien

```bash
docker build -t isbn_validator .
docker run --rm -p 8021:8021 isbn_validator
```

De service draait dan op http://localhost:8021


## Endpoints en testcommando's

### POST /validate

Valideert een ISBN-10 of ISBN-13 code. Accepteert input met of zonder hyphens/spaties. Retourneert of de code geldig is en welk formaat het is.

```bash
curl -X POST http://localhost:8021/validate -H 'Content-Type: application/json' -d '{"isbn": "978-3-16-148410-0"}'
```

**Response:**
```json
{
  "valid": true,
  "format": "ISBN-13",
  "normalized": "9783161484100",
  "input": "978-3-16-148410-0"
}
```

### GET /validate

Valideert een ISBN-10 of ISBN-13 code via query parameter. Handig voor snelle checks via de browser of curl.

```bash
curl -X GET 'http://localhost:8021/validate?isbn=0306406152'
```

**Response:**
```json
{
  "valid": true,
  "format": "ISBN-10",
  "normalized": "0306406152",
  "input": "0306406152"
}
```
