# json_key_sorter

Een microservice die een JSON object accepteert en de keys alfabetisch gesorteerd teruggeeft.

## Lokaal draaien

```bash
docker build -t json_key_sorter .
docker run --rm -p 8017:8017 json_key_sorter
```

De service draait dan op http://localhost:8017


## Endpoints en testcommando's

### POST /sort-keys

Neemt een JSON object en geeft een nieuw object terug waarvan de keys alfabetisch gesorteerd zijn (recursief voor geneste objecten).

```bash
curl -X POST http://localhost:8017/sort-keys -H 'Content-Type: application/json' -d '{"data": {"banana": 1, "apple": 2, "cherry": {"zeta": 0, "alpha": 1}}}'
```

**Response:**
```json
{
  "sorted": {
    "apple": 2,
    "banana": 1,
    "cherry": {
      "alpha": 1,
      "zeta": 0
    }
  },
  "keys": [
    "apple",
    "banana",
    "cherry"
  ]
}
```
