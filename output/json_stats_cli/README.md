# json_stats_cli

Een Python CLI tool die een lijst getallen leest uit een JSON bestand en de som, gemiddelde en maximum berekent en teruggeeft.

## Gebruik

```
python src/main.py <pad_naar_json_bestand>
```

## Vereisten

- Python 3.6+
- pytest
- click

## Installatie

```
pip install -r requirements.txt
```

## Tests

```
pytest
```
