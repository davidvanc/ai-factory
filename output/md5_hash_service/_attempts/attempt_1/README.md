# md5_hash_service

Een HTTP microservice die een string accepteert en de bijbehorende MD5 hash retourneert.

## Lokaal draaien

```bash
docker build -t md5_hash_service .
docker run --rm -p 8018:8018 md5_hash_service
```

De service draait dan op http://localhost:8018


## Endpoints en testcommando's

### POST /hash

Berekent de MD5 hash van de meegegeven string en retourneert deze als hexadecimale waarde.

```bash
curl -X POST http://localhost:8018/hash -H 'Content-Type: application/json' -d '{"text": "hello world"}'
```

**Response:**
```json
{
  "text": "hello world",
  "md5": "5eb63bbbe01eeed093cb22bb8f5acdc3"
}
```

### GET /hash

Berekent de MD5 hash van een string meegegeven als query parameter.

```bash
curl -X GET 'http://localhost:8018/hash?text=hello%20world'
```

**Response:**
```json
{
  "text": "hello world",
  "md5": "5eb63bbbe01eeed093cb22bb8f5acdc3"
}
```

### GET /status

Health check endpoint voor de service.

```bash
curl -X GET http://localhost:8018/status
```

**Response:**
```json
{
  "status": "ok"
}
```
