# morse_converter

Een Python CLI tool die tekst converteert naar morse code en morse code terug naar tekst.

## Lokaal draaien

```bash
docker build -t morse_converter .
docker run --rm morse_converter
```

Voor een CLI tool met argumenten:
```bash
docker run --rm morse_converter python -m src.main --help
```

## Tests draaien

```bash
docker run --rm morse_converter python -m pytest tests/ -v
```

## Project structuur

- `src/` - source code
- `tests/` - tests
- `Dockerfile` - container definitie
- `requirements.txt` - Python dependencies
- `.env.example` - voorbeeld environment variabelen

## Configuratie

Kopieer `.env.example` naar `.env` en pas aan indien nodig:

```bash
cp .env.example .env
```
