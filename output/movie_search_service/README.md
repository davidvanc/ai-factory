# movie_search_service

HTTP microservice voor het beheren en zoeken van films. Ondersteunt het toevoegen van films, ophalen van alle films met optionele filtering op genre en jaar, en het ophalen van een specifieke film op id.

## Lokaal draaien

```bash
docker build -t movie_search_service .
docker run --rm -p 8027:8027 movie_search_service
```

De service draait dan op http://localhost:8027


## Endpoints en testcommando's

### POST /movies

Voegt een nieuwe film toe. Retourneert de aangemaakte film inclusief gegenereerd id en added_at timestamp.

```bash
curl -X POST http://localhost:8027/movies -H 'Content-Type: application/json' -d '{"title": "Mad Max: Fury Road", "genre": "action", "year": 2015}'
```

**Response:**
```json
{
  "id": "a1b2c3d4",
  "title": "Mad Max: Fury Road",
  "genre": "action",
  "year": 2015,
  "added_at": "2024-05-20T14:30:00Z"
}
```

### GET /movies

Retourneert alle films. Optionele query parameters: genre (filtert op genre) en year (filtert op jaar). Combinatie van beide filters versmalt verder.

```bash
curl -X GET 'http://localhost:8027/movies?genre=action&year=2020'
```

**Response:**
```json
{
  "movies": [
    {
      "id": "a1b2c3d4",
      "title": "Tenet",
      "genre": "action",
      "year": 2020,
      "added_at": "2024-05-20T14:30:00Z"
    }
  ]
}
```

### GET /movies/{id}

Retourneert een specifieke film op basis van id. Geeft 404 als de film niet bestaat.

```bash
curl -X GET http://localhost:8027/movies/a1b2c3d4
```

**Response:**
```json
{
  "id": "a1b2c3d4",
  "title": "Mad Max: Fury Road",
  "genre": "action",
  "year": 2015,
  "added_at": "2024-05-20T14:30:00Z"
}
```
