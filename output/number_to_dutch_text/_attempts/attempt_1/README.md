# number_to_dutch_text

Microservice die getallen tot 999999999,99 omzet naar Nederlandse tekst (bijv. 1 -> één, 15 -> vijftien)

## Lokaal draaien

```bash
docker-compose up --build
```

De service draait dan op http://localhost:8080

## Tests draaien

```bash
docker run --rm number_to_dutch_text python -m pytest tests/ -v
```

## Project structuur

- `src/` - source code
- `tests/` - tests
- `Dockerfile` - container definitie
- `requirements.txt` - Python dependencies
- `.env.example` - voorbeeld environment variabelen

## Configuratie

Kopieer `.env.example` naar `.env` en pas aan indien nodig:

```bash
cp .env.example .env
```
