# palindroom_checker

Een Python CLI tool die controleert of een woord of zin een palindroom is, waarbij hoofdletters en spaties worden genegeerd.

## Lokaal draaien

```bash
docker build -t palindroom_checker .
docker run --rm palindroom_checker
```

Voor een CLI tool met argumenten:
```bash
docker run --rm palindroom_checker python -m src.main --help
```

## Tests draaien

```bash
docker run --rm palindroom_checker python -m pytest tests/ -v
```
