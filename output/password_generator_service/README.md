# password_generator_service

Een HTTP microservice die veilige wachtwoorden genereert met instelbare lengte en optionele inclusie van cijfers, hoofdletters, kleine letters en speciale tekens.

## Lokaal draaien

```bash
docker build -t password_generator_service .
docker run --rm -p 8013:8013 password_generator_service
```

De service draait dan op http://localhost:8013


## Endpoints en testcommando's

### POST /generate

Genereert een wachtwoord met de opgegeven lengte en karaktergroepen. Lengte moet tussen 8 en 128 zijn en minstens één karaktergroep moet ingeschakeld zijn.

```bash
curl -X POST http://localhost:8013/generate -H 'Content-Type: application/json' -d '{"length": 16, "include_digits": true, "include_uppercase": true, "include_lowercase": true, "include_symbols": true}'
```

**Response:**
```json
{
  "password": "aB3$xK9!mQ2@wZ7#",
  "length": 16
}
```
