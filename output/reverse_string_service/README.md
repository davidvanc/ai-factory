# reverse_string_service

Een HTTP microservice met een POST /reverse endpoint die een string omkeert

## Lokaal draaien

```bash
docker build -t reverse_string_service .
docker run --rm -p 8001:8001 reverse_string_service
```

De service draait dan op http://localhost:8001


## Endpoints en testcommando's

### POST /reverse

Keert de meegegeven string om en geeft het resultaat terug

```bash
curl -X POST http://localhost:8001/reverse -H 'Content-Type: application/json' -d '{"text": "hello world"}'
```

**Response:**
```json
{
  "reversed": "dlrow olleh"
}
```
