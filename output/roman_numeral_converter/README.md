# roman_numeral_converter

Microservice die conversies uitvoert tussen Romeinse cijfers en gehele getallen (1-3999) met subtraction notation (IV, IX, XL, XC, CD, CM).

## Lokaal draaien

```bash
docker build -t roman_numeral_converter .
docker run --rm -p 8020:8020 roman_numeral_converter
```

De service draait dan op http://localhost:8020


## Endpoints en testcommando's

### POST /to-roman

Converteert een geheel getal (1-3999) naar een Romeins cijfer met subtraction notation.

```bash
curl -X POST http://localhost:8020/to-roman -H 'Content-Type: application/json' -d '{"number": 1994}'
```

**Response:**
```json
{
  "number": 1994,
  "roman": "MCMXCIV"
}
```

### POST /to-integer

Converteert een Romeins cijfer naar een geheel getal. Accepteert alleen canonieke vorm met subtraction notation.

```bash
curl -X POST http://localhost:8020/to-integer -H 'Content-Type: application/json' -d '{"roman": "MCMXCIV"}'
```

**Response:**
```json
{
  "roman": "MCMXCIV",
  "number": 1994
}
```

### GET /convert

Automatische conversie op basis van het type van de query parameter 'value'. Geeft het tegenovergestelde formaat terug.

```bash
curl -X GET 'http://localhost:8020/convert?value=XLII'
```

**Response:**
```json
{
  "input": "XLII",
  "input_type": "roman",
  "output": 42,
  "output_type": "integer"
}
```

### GET /status

Gezondheidscheck endpoint voor de service.

```bash
curl -X GET http://localhost:8020/status
```

**Response:**
```json
{
  "status": "ok",
  "service": "roman_numeral_converter",
  "range": "1-3999"
}
```
