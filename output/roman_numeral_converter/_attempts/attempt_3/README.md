# roman_numeral_converter

HTTP microservice that converts between Roman numerals and integers (1-3999) using standard subtraction notation (IV, IX, XL, XC, CD, CM).

## Lokaal draaien

```bash
docker build -t roman_numeral_converter .
docker run --rm -p 8020:8020 roman_numeral_converter
```

De service draait dan op http://localhost:8020


## Endpoints en testcommando's

### POST /to-roman

Convert an integer (1-3999) to a Roman numeral string using subtraction notation.

```bash
curl -X POST http://localhost:8020/to-roman -H 'Content-Type: application/json' -d '{"number": 1994}'
```

**Response:**
```json
{
  "number": 1994,
  "roman": "MCMXCIV"
}
```

### POST /to-integer

Convert a Roman numeral string to its integer value. Only valid canonical Roman numerals using subtraction notation are accepted.

```bash
curl -X POST http://localhost:8020/to-integer -H 'Content-Type: application/json' -d '{"roman": "MCMXCIV"}'
```

**Response:**
```json
{
  "roman": "MCMXCIV",
  "number": 1994
}
```

### GET /convert

Auto-detect conversion: pass either 'number' or 'roman' as a query parameter and receive the converted value.

```bash
curl -X GET 'http://localhost:8020/convert?number=42'
```

**Response:**
```json
{
  "number": 42,
  "roman": "XLII"
}
```

### GET /status

Health check endpoint returning service status and supported range.

```bash
curl -X GET http://localhost:8020/status
```

**Response:**
```json
{
  "status": "ok",
  "min": 1,
  "max": 3999
}
```
