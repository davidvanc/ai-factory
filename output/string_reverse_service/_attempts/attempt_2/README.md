# string_reverse_service

HTTP microservice die strings omkeert via POST /reverse. Ondersteunt Unicode-bewuste omkering (grapheme clusters optioneel), lege-string edge cases en een health endpoint voor monitoring.

## Lokaal draaien

```bash
docker build -t string_reverse_service .
docker run --rm -p 8003:8003 string_reverse_service
```

De service draait dan op http://localhost:8003


## Endpoints en testcommando's

### POST /reverse

Keert de meegegeven string om. Met 'unicode_safe': true wordt omgekeerd op basis van grapheme clusters zodat samengestelde emoji en diacritische tekens intact blijven; bij false wordt per code point omgekeerd.

```bash
curl -X POST http://localhost:8003/reverse -H 'Content-Type: application/json' -d '{"text": "Hallo wereld", "unicode_safe": true}'
```

**Response:**
```json
{
  "original": "Hallo wereld",
  "reversed": "dlerew ollaH",
  "length": 12,
  "unicode_safe": true
}
```

### POST /reverse/batch

Keert een lijst van strings om in één request. Maximaal 1000 items per request.

```bash
curl -X POST http://localhost:8003/reverse/batch -H 'Content-Type: application/json' -d '{"items": ["abc", "FastAPI", "🇳🇱"], "unicode_safe": true}'
```

**Response:**
```json
{
  "results": [
    {
      "original": "abc",
      "reversed": "cba",
      "length": 3
    },
    {
      "original": "FastAPI",
      "reversed": "IPAtsaF",
      "length": 7
    },
    {
      "original": "🇳🇱",
      "reversed": "🇳🇱",
      "length": 2
    }
  ],
  "count": 3,
  "unicode_safe": true
}
```

### GET /reverse

Gemaksvariant voor eenvoudige data: keert de string uit de query parameter 'text' om.

```bash
curl -X GET 'http://localhost:8003/reverse?text=microservice&unicode_safe=false'
```

**Response:**
```json
{
  "original": "microservice",
  "reversed": "ecivresorcim",
  "length": 12,
  "unicode_safe": false
}
```

### GET /status

Health- en versie-informatie van de service voor readiness/liveness checks.

```bash
curl -X GET http://localhost:8003/status
```

**Response:**
```json
{
  "status": "ok",
  "service": "string_reverse_service",
  "version": "1.0.0"
}
```
