# string_reverser

Een HTTP microservice die een string omkeert via een POST endpoint

## Lokaal draaien

```bash
docker build -t string_reverser .
docker run --rm -p 8016:8016 string_reverser
```

De service draait dan op http://localhost:8016


## Endpoints en testcommando's

### POST /reverse

Keert de gegeven string om en retourneert het resultaat

```bash
curl -X POST http://localhost:8016/reverse -H 'Content-Type: application/json' -d '{"text": "hello world"}'
```

**Response:**
```json
{
  "reversed": "dlrow olleh"
}
```
