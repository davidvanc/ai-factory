# task_scheduler_service

Een FastAPI microservice die een lijst met taken (events) accepteert, conflicten detecteert op basis van overlap in tijd, en een optimaal schema genereert door taken met lagere prioriteit te verplaatsen naar het eerstvolgende vrije slot. Indien verplaatsen niet mogelijk is, wordt de taak gemarkeerd als Failed. Geïnspireerd door open evenementen kalenders zoals Open Data Day 2026 en Open Data Week 2026.

## Lokaal draaien

```bash
docker build -t task_scheduler_service .
docker run --rm -p 8022:8022 task_scheduler_service
```

De service draait dan op http://localhost:8022


## Endpoints en testcommando's

### POST /schedule

Accepteert een lijst met taken en retourneert een geoptimaliseerd schema met conflictresolutie op basis van prioriteit.

```bash
curl -X POST http://localhost:8022/schedule -H 'Content-Type: application/json' -d '{"tasks":[{"name":"Open Data Day Panel","start_time":"2026-03-07T10:00:00","duration":60,"priority":5},{"name":"Community Meetup","start_time":"2026-03-07T10:30:00","duration":45,"priority":2}]}'
```

**Response:**
```json
{
  "scheduled": [
    {
      "name": "Open Data Day Panel",
      "start_time": "2026-03-07T10:00:00",
      "end_time": "2026-03-07T11:00:00",
      "duration": 60,
      "priority": 5,
      "status": "Scheduled"
    },
    {
      "name": "Community Meetup",
      "start_time": "2026-03-07T11:00:00",
      "end_time": "2026-03-07T11:45:00",
      "duration": 45,
      "priority": 2,
      "status": "Rescheduled"
    },
    {
      "name": "Data Workshop",
      "start_time": "2026-03-07T12:00:00",
      "end_time": "2026-03-07T13:30:00",
      "duration": 90,
      "priority": 4,
      "status": "Scheduled"
    }
  ],
  "failed": []
}
```

### POST /detect-conflicts

Detecteert conflicten (overlappende taken) in een lijst zonder ze op te lossen.

```bash
curl -X POST http://localhost:8022/detect-conflicts -H 'Content-Type: application/json' -d '{"tasks":[{"name":"Task A","start_time":"2026-03-22T09:00:00","duration":60,"priority":3},{"name":"Task B","start_time":"2026-03-22T09:30:00","duration":30,"priority":4}]}'
```

**Response:**
```json
{
  "conflicts": [
    {
      "task_a": "Task A",
      "task_b": "Task B",
      "overlap_minutes": 30
    }
  ],
  "total_conflicts": 1
}
```
