# temperature_converter

Een microservice die temperaturen converteert tussen Celsius en Fahrenheit via HTTP endpoints

## Lokaal draaien

```bash
docker build -t temperature_converter .
docker run --rm -p 8019:8019 temperature_converter
```

De service draait dan op http://localhost:8019


## Endpoints en testcommando's

### POST /convert/celsius-to-fahrenheit

Converteert een temperatuur van Celsius naar Fahrenheit

```bash
curl -X POST http://localhost:8019/convert/celsius-to-fahrenheit -H 'Content-Type: application/json' -d '{"value": 100.0}'
```

**Response:**
```json
{
  "input": 100.0,
  "input_unit": "Celsius",
  "output": 212.0,
  "output_unit": "Fahrenheit"
}
```

### POST /convert/fahrenheit-to-celsius

Converteert een temperatuur van Fahrenheit naar Celsius

```bash
curl -X POST http://localhost:8019/convert/fahrenheit-to-celsius -H 'Content-Type: application/json' -d '{"value": 212.0}'
```

**Response:**
```json
{
  "input": 212.0,
  "input_unit": "Fahrenheit",
  "output": 100.0,
  "output_unit": "Celsius"
}
```

### POST /convert

Converteert een temperatuur tussen opgegeven units (C of F)

```bash
curl -X POST http://localhost:8019/convert -H 'Content-Type: application/json' -d '{"value": 0.0, "from_unit": "C", "to_unit": "F"}'
```

**Response:**
```json
{
  "input": 0.0,
  "input_unit": "C",
  "output": 32.0,
  "output_unit": "F"
}
```

### GET /status

Health check endpoint

```bash
curl http://localhost:8019/status
```

**Response:**

```json
  "service": "temperature_converter"
}
```
