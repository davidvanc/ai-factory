# text_analyzer

Een microservice die woorden of zinnen analyseert en informatie teruggeeft zoals aantal letters, aantal woorden, aantal klinkers en of het een palindroom is.

## Lokaal draaien

```bash
docker build -t text_analyzer .
docker run --rm -p 8005:8005 text_analyzer
```

De service draait dan op http://localhost:8005


## Endpoints en testcommando's

### POST /analyze

Analyseert een tekst en retourneert aantal letters, aantal woorden, aantal klinkers en of het een palindroom is.

```bash
curl -X POST http://localhost:8000/analyze -H 'Content-Type: application/json' -d '{"text": "Lepel"}'
```

**Response:**
```json
{
  "text": "Lepel",
  "letter_count": 5,
  "word_count": 1,
  "vowel_count": 2,
  "is_palindrome": true
}
```

### GET /analyze

Analyseert een tekst via query parameter en retourneert dezelfde analyse als de POST variant.

```bash
curl -X GET 'http://localhost:8000/analyze?text=Hallo%20wereld'
```

**Response:**
```json
{
  "text": "Hallo wereld",
  "letter_count": 11,
  "word_count": 2,
  "vowel_count": 4,
  "is_palindrome": false
}
```

### GET /status

Health check endpoint dat de status van de service teruggeeft.

```bash
curl -X GET http://localhost:8000/status
```

**Response:**
```json
{
  "status": "ok"
}
```

### GET /health

```bash
curl http://localhost:8005/health
```
