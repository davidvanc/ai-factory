# text_analyzer

Een HTTP microservice die woorden of zinnen analyseert en teruggeeft: aantal letters, aantal woorden, aantal klinkers, en of het een palindroom is.

## Lokaal draaien

```bash
docker build -t text_analyzer .
docker run --rm -p 8005:8005 text_analyzer
```

De service draait dan op http://localhost:8005


## Endpoints en testcommando's

### POST /analyze

Analyseert een woord of zin en geeft statistieken terug: aantal letters, aantal woorden, aantal klinkers en of het een palindroom is.

```bash
curl -X POST http://localhost:8000/analyze -H 'Content-Type: application/json' -d '{"text": "Racecar is snel"}'
```

**Response:**
```json
{
  "text": "Racecar is snel",
  "letter_count": 13,
  "word_count": 3,
  "vowel_count": 5,
  "is_palindrome": false
}
```

### GET /analyze

Analyseert een woord of zin via query parameter en geeft dezelfde statistieken terug.

```bash
curl -X GET 'http://localhost:8000/analyze?text=lepel'
```

**Response:**
```json
{
  "text": "lepel",
  "letter_count": 5,
  "word_count": 1,
  "vowel_count": 2,
  "is_palindrome": true
}
```

### GET /health

Health check endpoint om te verifiëren dat de service draait.

```bash
curl -X GET http://localhost:8000/health
```

**Response:**
```json
{
  "status": "ok"
}
```
