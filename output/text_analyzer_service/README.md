# text_analyzer_service

Een HTTP microservice die woorden of zinnen analyseert en teruggeeft: aantal letters, aantal woorden, aantal klinkers, en of het een palindroom is.

## Lokaal draaien

```bash
docker build -t text_analyzer_service .
docker run --rm -p 8006:8006 text_analyzer_service
```

De service draait dan op http://localhost:8006


## Endpoints en testcommando's

### POST /analyze

Analyseert een gegeven tekst en retourneert statistieken: aantal letters, aantal woorden, aantal klinkers en of het een palindroom is.

```bash
curl -X POST http://localhost:8000/analyze -H 'Content-Type: application/json' -d '{"text": "Lepel"}'
```

**Response:**
```json
{
  "text": "Lepel",
  "letter_count": 5,
  "word_count": 1,
  "vowel_count": 2,
  "is_palindrome": true
}
```

### GET /analyze

Analyseert een tekst via query parameter (handig voor korte input).

```bash
curl -X GET 'http://localhost:8000/analyze?text=hallo%20wereld'
```

**Response:**
```json
{
  "text": "hallo wereld",
  "letter_count": 11,
  "word_count": 2,
  "vowel_count": 4,
  "is_palindrome": false
}
```

### GET /status

Health check endpoint voor de service.

```bash
curl -X GET http://localhost:8000/status
```

**Response:**
```json
{
  "status": "ok",
  "service": "text_analyzer_service"
}
```

### GET /health

```bash
curl http://localhost:8006/health
```
