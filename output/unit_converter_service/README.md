# unit_converter_service

HTTP microservice voor het converteren van lengte, gewicht en temperatuur tussen verschillende eenheden.

## Lokaal draaien

```bash
docker build -t unit_converter_service .
docker run --rm -p 8029:8029 unit_converter_service
```

De service draait dan op http://localhost:8029


## Endpoints en testcommando's

### POST /convert/length

Converteert een lengtewaarde tussen meters, feet, miles en kilometers.

```bash
curl -X POST http://localhost:8029/convert/length -H 'Content-Type: application/json' -d '{"value": 100, "from_unit": "meters", "to_unit": "feet"}'
```

**Response:**
```json
{
  "from_unit": "meters",
  "to_unit": "feet",
  "result": 328.084
}
```

### POST /convert/weight
