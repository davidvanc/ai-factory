# uv_index_scraper

Python tool die de UV-index voor Uccle (Brussel) ophaalt via HTML scraping van meteo.be met BeautifulSoup en advies geeft over zonbescherming volgens WHO-richtlijnen.

## Lokaal draaien

```bash
docker build -t uv_index_scraper .
docker run --rm uv_index_scraper
```

Voor een CLI tool met argumenten:
```bash
docker run --rm uv_index_scraper python -m src.main --help
```

## Tests draaien

```bash
docker run --rm uv_index_scraper python -m pytest tests/ -v
```

## Project structuur

- `src/` - source code

- `requirements.txt` - Python dependencies
